# Security

OpenChip runs entirely in the browser. It has no server, no accounts and no
database, and nothing you draw is sent anywhere. The main risks are in how the
app reads files you open, such as a crafted `.openchip` file.

If you find a security problem, please email **info@openchip.tech** rather than
opening a public issue. Include steps to reproduce it. You'll get a reply, and a
fix will be released as soon as practical.
